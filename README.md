# ZmNRL1 - computational evidence and reproducibility

Derived computational evidence and source-audited code for the research project: Sequence-validated phylogenetic and cross-study transcriptomic context for ZmNRL1 under nitrogen perturbation in maize.

Public primary datasets: GEO accession GSE252822 (raw counts); GEO accession GSE312408 (descriptive TPM).

This repository includes selected author-generated derived tabular evidence, scripts, and source-to-claim documentation. It excludes third-party raw GEO/SRA/NCBI/MaizeGDB/TAIR datasets and the unapproved research manuscript. Source accessions must be obtained from their official providers.

Scientific limitations: Orthology relationships are computational, not proof of function. Composition bias and alignment missingness remain. Seven Ka/Ks estimates are exploratory; one pair is withheld. Primary maize GO enrichment was not released. miRNA predictions are not experimentally validated. AtNRG2.10, AtNRG2.15 and ZmNRG2.7 published aliases have not been reconciled to project gene IDs.

Public code and derived data are provided for review at a versioned Git commit. The commit hash is not a DOI. No data/code reuse license is asserted without author approval.
